# U3-ejercicio24
# Gestión de Dispositivos Electrónicos y Multimedia

## Objetivo principal

Diseñar una jerarquía de clases en Java para representar dispositivos electrónicos generales y especializados, utilizando herencia y sobrescritura de métodos.

## Descripción

Se desarrolla una clase base `Dispositivo` que contiene los atributos comunes de los productos electrónicos: marca, modelo y precio base.

A partir de esta clase se implementan las subclases `Smartphone` y `Laptop`, que incorporan sus propias especificaciones técnicas.

Cada subclase sobrescribe el método `mostrarInformacion()` para mostrar los datos generales heredados junto con sus características particulares.

## Conceptos aplicados

- Herencia
- Encapsulamiento
- Constructores
- Uso de `super`
- Sobrescritura de métodos (`@Override`)
- Polimorfismo
